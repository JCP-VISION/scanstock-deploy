Configuration

Complete reference for all environment variables supported by ScanStock.

🔑 Core Application Settings

These values are required for initial setup and account initialization.

Variable Description
LICENSE_KEY Your ScanStock license key issued by JCP-VISION.
DJANGO_SUPERUSER_USERNAME Administrator username created during first startup.
DJANGO_SUPERUSER_PASSWORD Administrator password.
DJANGO_SUPERUSER_EMAIL Administrator email address.

🗄 Database Configuration

By default, ScanStock uses SQLite stored in the persistent volume. For enterprise deployments, use external databases by setting CUSTOM_ENGINE=true.

Variable Description
CUSTOM_ENGINE Set to true to enable external database configuration.
DB_ENGINE Backend: django.db.backends.mysql or postgresql.
DB_NAME Database name.
DB_HOST Database host address.
DB_PORT Database port (3306 for MySQL, 5432 for Postgres).

🖨 Printer Integration

Optional settings for connecting to warehouse label printers.

Variable Description
PRINTER_MODE Connection type: local or network.
PRINTER_HOST Printer IP address.
PRINTER_PORT Printer communication port (default 9100).
