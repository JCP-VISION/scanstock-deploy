ScanStock Deployment Guide

Welcome to the official ScanStock setup and deployment resource. This guide is designed to help you get your warehouse and factory operations running efficiently using our Docker-based platform.

Deployment Resources: This documentation site provides the necessary templates and configurations to deploy ScanStock on your server. Please note that the proprietary application source code is provided separately via our secure container registry.

ScanStock is a premium inventory and barcode scanning platform engineered for high-performance warehouse management. By utilizing Docker, we ensure a consistent, secure, and easily maintainable environment for your critical operations.

This documentation covers:

  • Step-by-step installation and environment preparation.
  • Docker Compose configuration for rapid deployment.
  • Comprehensive environment variable reference for customization.
  • Integration guidelines for hardware such as label printers.

Quick Start

To begin the deployment process, you will first need to pull the ScanStock container image from our registry. We recommend using the GitHub Container Registry for the latest stable releases.

docker pull ghcr.io/jcp-vision/scanstock:latest
