ScanStock Deployment

Official deployment resources for running ScanStock using Docker containers.

Proprietary Software: This repository does not contain the proprietary ScanStock application source code. It contains the deployment templates required to run the platform.

ScanStock is a premium inventory and barcode scanning platform designed for high-efficiency warehouse and factory operations.

This documentation provides comprehensive guides for:

  • Official deployment documentation
  • Docker Compose configuration
  • Environment configuration templates
  • Example integration components

Quick Start

The fastest way to get started is by pulling the ScanStock image from the GitHub Container Registry.

docker pull ghcr.io/jcp-vision/scanstock:latest
