API Reference

Integration guide and system monitoring endpoints for ScanStock.

Health Check

Use this endpoint to monitor the deployment status of the documentation service.

GET /health

Example Request

curl https://scanstock-docs.jcp-vision.com/health

Response

{
  "status": "ok",
  "service": "scanstock-docs",
  "version": "1.0.0"
}
